# Ankit Joshi: Personal Website

## Status
A minimal HTML page containing a personal introduction. This is a website starting point, not a completed project portfolio.

## View locally
Open `index.html` in a browser, or serve the folder:
```sh
python3 -m http.server 8000
```
Visit http://localhost:8000.

## For reviewers
No backend, API integration, build step, or automated tests are present. GitHub Pages hosting has not been verified for this repository.
